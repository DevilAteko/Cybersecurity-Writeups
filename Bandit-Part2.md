My Journey Through OverTheWire Bandit (Part 2)
Introduction:
If the first 15 levels of Bandit were training wheels, the rest of the game completely ripped them off. The levels ahead were full of surprises and offered far fewer hints to guide me. Honestly, some levels were so hard that they made me feel like giving up entirely. The new terminologies and concepts felt incredibly tough to grasp at first. Without using AI as a tutor to break down exactly what was happening under the hood, I would have been completely lost. But I pushed through, and what I learned in these final levels changed how I look at Linux.

Section 1: Escalating Privileges
In this section, I learned about SUID (Set Owner User ID). I learned how setting the SUID permission on an executable file allows anyone who runs it to temporarily gain the privileges of the file's owner. In the Bandit game, I found an executable that had SUID enabled. By passing commands into it, I was able to read files that were completely locked to my normal user account!
After that, I was introduced to cron jobs, which are used in Linux to automate tasks periodically. Instead of just reading the automated tasks, I learned how to exploit them. I wrote my own custom bash script, dropped it into a specific directory, and waited for the server's automated cron system to execute my script with higher privileges, which bypassed the security and handed me the password.
Section 2: Writing My First Scripts
Level 24 was definitely not simple. The challenge required me to submit a secret 4-digit pincode, and there was no hidden file to read—my only choice was to guess every single number. Instead of typing 10,000 combinations by hand, I took a detour to learn the basics of Bash scripting. I wrote my very first script using a for loop to automatically generate the numbers and brute-force the level in seconds.

Section 3: Escaping The Traps
Level 25 was another level that honestly made me want to cry. The server was rigged to instantly log me out the second I connected. I wouldn’t have survived this level without some guidance. I learned a crazy trick: I bypassed the automatic logout by physically shrinking my terminal window size to force the text to pause. While it was paused, I opened the vi text editor, and commanded the editor to spawn a real shell (:set shell=/bin/bash). It was a crazy level that taught me how even the physical size of a window can be used in an exploit.
Level 32 was a similar trap, but after some research, it wasn't too tough. The custom shell turned every command I typed into UPPERCASE, which breaks Linux. I realized that to escape, I needed a command that didn't use alphabetical characters. Recalling basic bash concepts, I remembered the $0 variable, which represents the current terminal (sh). Because symbols and numbers can't be made uppercase, typing $0 successfully spawned a new sub-shell. Even better, that rigged uppercase program had SUID enabled for bandit33, meaning my new sub-shell inherited bandit33's privileges, allowing me to easily grab the password!
Section 4: Mastering Git
Surprisingly, this turned out to be the easiest part of Bandit for me. I had never studied Git before, and even now, I didn't dive deep into the underlying theory. My entire strategy was just reading the documentation, understanding the problem, and finding exactly what I needed. The better you are at reading docs, the faster this section goes. Using this method, I was able to figure out how to clone repositories, dig through the git log history to find deleted passwords, swap to hidden branches, and even force-push files back to the server bypassing .gitignore rules.

Conclusion 
OverTheWire Bandit taught me that the cybersecurity journey will be one where I will often feel lost and want to break down. But I can't stop; I have to keep looking. I learned to use Google like a dictionary to figure things out on the fly. After all, this field is about safety and security—it can’t be easy. Going from knowing absolutely nothing to getting comfortable with feeling stuck, never giving up, and finally understanding just how powerful the Linux command line really is, has been an incredible experience.
